# 📱 Desafio Pokedex - DIO

Bem-vindo(a) ao meu projeto de Pokédex! Este repositório faz parte do desafio da Digital Innovation One (DIO) e foi desenvolvido com foco em aprimorar habilidades em **JavaScript**, **CSS** e **HTML**. Aqui, você encontrará uma aplicação web moderna, interativa e visualmente atraente, criada para demonstrar minha capacidade de construir interfaces responsivas e consumir APIs públicas.

## ✨ Destaques do Projeto

- **Design Responsivo:** Interface adaptável para dispositivos móveis e desktops.
- **Busca Dinâmica:** Pesquise qualquer Pokémon pelo nome ou número.
- **Detalhes Interativos:** Veja informações completas, incluindo tipos, habilidades e imagens animadas.
- **Consumo de API:** Integração com a [PokéAPI](https://pokeapi.co/) para dados sempre atualizados.
- **Experiência do Usuário:** Animações suaves e feedback visual para uma navegação envolvente.

## 💡 Aprendizados

Este projeto foi uma oportunidade para:

- Praticar componentes de interface modernos usando flexbox e grid;
- Consumir dados de APIs REST com JavaScript puro;
- Gerenciar estados da aplicação e navegação entre diferentes telas;
- Trabalhar com eventos, manipulação do DOM e tratamento de erros.

# 🛠️ Como Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/elissandroa/desafio-pokedex-DIO.git
   ```
2. **Acesse a pasta do projeto:**
   ```bash
   cd desafio-pokedex-DIO
   ```
3. **Abra o arquivo `index.html` no seu navegador favorito.**
4. **Divirta-se explorando o universo Pokémon!**
